# 現代幾何推擠大對決

在同一支手機或平板上，兩個人一起玩的幾何對戰小遊戲。

## 玩法

- **相撲模式（雙人對抗）**：藍方用左下角的搖桿，紅方用右下角的搖桿。往想衝的方向拖曳，放開手指就會衝撞出去。先把對手推出圓圈的一方獲勝。
- **合作模式（雙人打王）**：藍方用左邊（左上角搖桿移動、左下角「射擊」鈕攻擊），紅方用右邊（右上角搖桿移動、右下角「射擊」鈕攻擊），射擊會自動瞄準魔王，移動和射擊可以同時進行。兩人要合力在被擊中 20 次之前打倒 75 血的魔王，魔王每 1.5 秒會射一發子彈。

## 線上遊玩

本遊戲透過 GitHub Pages 發佈，用瀏覽器打開 repo 的 Pages 網址就能直接玩。
